# Workspace Reservation Management

A scoped ServiceNow application designed to help employees request, reserve, and manage shared workspaces through a structured approval and fulfillment process.

## Project Overview

The Workspace Reservation Management application was created to demonstrate how ServiceNow can be used to manage shared workspace requests from submission through approval, occupancy, and maintenance.

The application includes role-based access, automated workflows, request tracking, notifications, and a branded user-facing portal.

## Key Features

- Custom scoped ServiceNow application
- Custom tables for workspace and reservation management
- Three-tier role architecture
- Access Control Lists (ACLs)
- Record Producers
- Service Catalog functionality
- Flow Designer approval workflow
- Business Rules
- SLA definitions
- Email notifications
- UI Actions
- Data governance policies
- Branded NexSpace Service Portal
- REST API integration with an external webhook service for real-time notifications

## Workflow

The application supports the workspace lifecycle from beginning to end:

1. A user submits a workspace reservation request.
2. The request is evaluated through an approval workflow.
3. Approved reservations move through occupancy and fulfillment stages.
4. Business Rules and automated processes update records throughout the lifecycle.
5. Notifications keep users informed of reservation activity.
6. Workspace maintenance and availability can be tracked within the application.
